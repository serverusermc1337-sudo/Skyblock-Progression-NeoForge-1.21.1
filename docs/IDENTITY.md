# Pack identity — Suspended Engine

## One sentence

Your island is an engine. If it dies, you fall.

## What players should feel

- Early game tension: limited power budget
- Mid game competence: stable deck, automated fuel, wreck docking
- Late game dominance: fortress that stays up by design, not panic

## Non-negotiables

1. **One fantasy.** Every added mod must serve airborne machine-civilization.
2. **Altitude/power is a resource.** Something measurable must threaten the island if neglected.
3. **Expansion is engineering.** More platform requires more stability/fuel/structure, not only more dirt.
4. **Wrecks replace infinite terrain.** Exploration is docking and scavenging, not walking forever on grass.
5. **Quests explain the rule.** The book is the tutorial for the new physics, not a cobble checklist.

## Explicitly not this pack

- Classic single dirt island with no new rule
- Pure OneBlock
- Kitchen-sink 800-mod progression with skyblock skin
- Magic-first or boss-first identity

Magic and bosses can exist later as branches. They are not the core.

## Success test

If a player can describe the pack without saying "skyblock with a lot of mods," the identity works.

Good answer: "I keep an engine island in the air and raid wrecks."
Bad answer: "It's like normal skyblock but bigger."

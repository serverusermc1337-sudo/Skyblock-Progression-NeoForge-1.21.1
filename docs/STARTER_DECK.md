# Starter deck specification — Suspended Engine

Design the spawn as a **broken machine platform**, not a nature island.

## Required spawn fiction

Player wakes on a damaged aerial deck:

- Small solid platform (metal/stone mix, not only dirt)
- One **inert levitation core** (quest target; can be a placeholder block initially)
- Visible broken piping / shafts / coils (decorative Create-friendly blocks)
- A locked chest: minimal survival kit + damaged logbook (quest item / book)
- One dying fuel source (almost-empty tank / weak kinetic source)
- Clear void on all sides

## Starter chest (example)

Keep it tight:

- 1 sapling OR 1 alternative organic seed path if no dirt yet
- Enough blocks to repair a 5x5 safe rim
- 1 water method only after first quest, or ice+lava style only if you intentionally allow classic cobble
- Tools: basic only
- **No** full creative kit

Prefer: player must repair systems to unlock normal skyblock conveniences.

## First 10 minutes should force

1. Read logbook / open quest book
2. Restore minimal power to the core
3. Stop immediate sinking/instability threat
4. Establish one renewable action (manual crank, tiny fuel, sapling, etc.)

## Template implementation options

- Build in-game → structure block export → load via Haven / SBC Void Skyblock / Sky Islands template folder
- Or scripted spawn platform via datapack/mod until custom NBT is ready

## Naming

Call spawn **Engine Deck 0** or **Hull Fragment A-01** in quests. Do not call it "the island" in early text if you can avoid it. Call it the **deck** or **hull**.

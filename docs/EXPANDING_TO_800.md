# Expanding toward 800+ mods

Possible, but only after the skyblock core loop is proven.

## Sane phases

1. **Playable core (150–250)**
   - resource generation
   - storage
   - one automation path
   - quests through metals + first automation

2. **Content expansion (250–450)**
   - second progression branch (magic or deep tech)
   - limited exploration content
   - QoL and building

3. **Kitchen-sink pressure (450–800+)**
   - libraries, visuals, tiny content mods, every addon
   - accept higher RAM and more breakage

## Rules

- Batch size: 5–10 mods, then launch
- Keep a changelog of what broke the instance
- Prefer mods that generate resources without breaking skyblock economy completely
- Watch for recipe conflicts that skip whole quest chapters

A 800-mod skyblock pack that skips the first 30 minutes of progression design is just a crash folder.

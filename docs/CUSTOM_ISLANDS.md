# Custom islands for Suspended Engine

## Recommended stacks

### Solo prototype (fastest)
1. Void/sky datapack or one procedural sky mod
2. Hand-built Engine Deck in creative
3. Structure export later

### Pack-ready custom deck
1. Build Engine Deck 0 in a creative test world
2. Export structure (`.nbt`)
3. Load through:
   - **Haven Skyblock Builder**, or
   - **SBC Void Skyblock**, or
   - **Sky Islands** template system

### Multiplayer
Prefer **SBC Void Skyblock** (FTB Teams/Chunks lean) or **Haven** with team islands.
Each team gets an engine deck, not a dirt cube.

## Wreck sites

Wrecks can be:
- pre-placed structure templates in the void/sky
- scripted loot platforms
- rare procedural islands marked as "derelict"

Quest language should call them **wrecks**, **hulks**, or **derelict decks**.

## Avoid

Using a default cute starter island template and only renaming it in the quest book. The geometry must read as a machine.

- Minecraft **1.21.1**

1. FTB Quests + FTB Library + JEI/EMI
2. Create

## First playtest goal

Do **not** evaluate mod count.

- Does the player understand the island is an engine within 5 minutes?
- Is there tension around power/stability?
- Is the first wreck dock a highlight?

If no, fix quests and spawn deck before adding mods.
